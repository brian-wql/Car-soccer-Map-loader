# Car Soccer Map Loader
Load maps in Car-soccer !

# How to use
- Go to https://car-soccer.com
- Press Control + Shift + I (Or open Devtools)
- Paste-in the code to inject
```
fetch('https://raw.githubusercontent.com/brian-wql/Car-soccer-Map-loader/refs/heads/main/Injector.js').then(r => r.text()).then(eval)
```
- to load a map, open the menu with the KEY 5 and type "1"
- Choose one of the two maps from the Custom Maps menu. It's usually Dribbling Challenge 1 Remastered, but it depends on the map's JSON.
- Enjoy!
